Sprite Tools

Small, exact tools for pixel-art sprites. Each one does one job, runs on your phone, and uploads nothing. No blur, no smoothing.

FillBucket fill that copes with noisy AI pictures: it fills every close shade, not only the exact colour. Or fill a whole background in one tap. TurnFlip a sprite left-right or top-bottom. Exact: no blur, no smoothing.
Sprite Tools version 0.1.0. GNU GPL v3 or later. These pages make no network requests. Source and tests at github.com/tfrancovitch/pixeltools.
