# pixeltools

A small suite of tools for working with pixel-art sprites, built to streamline sprite work for Homestead and other projects.

Planned tools:

- **Pixel Snap**: finds the real pixel grid in an AI-generated "pixel art" image (for example from Midjourney) and shrinks it so one visible pixel becomes one actual pixel. A browser version and a Python version.
- **Sprite turner**: rotate and flip sprites without blurring.
- More as we think of them.
