# pixeltools

A small suite of tools for working with pixel-art sprites, built to streamline sprite work for Homestead and other projects.

## Tools

| Tool | What it does | Status |
|------|--------------|--------|
| [Pixel Snap](tools/pixel-snap/) | Finds the real pixel grid in an AI-generated "pixel art" image (for example from Midjourney) and shrinks it so one visible pixel becomes one actual pixel. Browser and Python versions. | Working |
| Sprite maker | Draws sprites from code: shapes and colour ramps in, tile-aligned sprite sheets out. | Planned |
| Sprite turner | Rotate and flip sprites without blurring. | Planned |

More as we think of them.
